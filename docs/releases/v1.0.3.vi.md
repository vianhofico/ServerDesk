# ServerDesk v1.0.3

[English](v1.0.3.md) | **Tiếng Việt**

ServerDesk v1.0.3 bổ sung trải nghiệm cài đặt Windows chuẩn, đồng thời vẫn giữ package portable.

## Đã bổ sung

- Thêm `ServerDesk-v1.0.3-win-x64-setup.exe`, installer Windows cài theo user hiện tại.
- Installer mặc định tạo shortcut ServerDesk ngoài Desktop và shortcut trong Start Menu.
- ServerDesk được đăng ký trong **Settings → Apps → Installed apps** của Windows và có uninstaller.
- Installer, app đã cài và các shortcut dùng đúng branding `serverdesk.ico` chính thức đã có sẵn và đang được WPF app embed.
- Dùng application ID ổn định để các installer release sau có thể upgrade cùng một ứng dụng đã cài.
- Vẫn giữ `ServerDesk-v1.0.3-win-x64.zip` làm lựa chọn portable.

## Safety gate của release

Release smoke giờ kiểm tra toàn bộ đường chạy của bản cài đặt trước khi setup được phép publish:

1. publish app Windows x64 self-contained;
2. chạy GUI từ package publish và xác nhận cửa sổ `ServerDesk` hiển thị ổn định;
3. compile Windows installer;
4. cài silent theo user hiện tại;
5. kiểm tra EXE đã cài, Desktop shortcut, Start Menu shortcut, nguồn icon và Windows uninstall registration;
6. chạy chính app đã cài và xác nhận GUI vẫn ổn định;
7. uninstall và kiểm tra EXE, shortcut, uninstall registration đã được dọn;
8. chỉ sau đó mới đóng gói setup EXE và ZIP portable để release.

`SHA256SUMS.txt` chứa checksum cho cả hai artifact release.

## Cài đặt

Để dùng theo kiểu app Windows bình thường, tải và chạy `ServerDesk-v1.0.3-win-x64-setup.exe`. Sau khi cài xong, mở ServerDesk từ Desktop hoặc Start Menu.

Xem [hướng dẫn cài trên Windows](../INSTALL.vi.md).

> Binary public hiện chưa được Authenticode/code-sign nên Windows SmartScreen có thể hiện cảnh báo unknown publisher.

Release này không thay đổi các boundary về feature/database đã certify.
