# ServerDesk v1.0.0

**English** | [Tiếng Việt](v1.0.0.vi.md)

ServerDesk v1.0.0 is the first consolidated V1 release after completion of the repository's M0–M8 roadmap.

## What this release is

A Windows x64 desktop client for visual administration of Linux servers using SSH/SFTP/PTY as the primary secure control plane, with optional SSH-tunneled realtime agent infrastructure.

The release workflow publishes:

- `ServerDesk-v1.0.0-win-x64.zip` — self-contained Windows x64 client package;
- `SHA256SUMS.txt` — SHA-256 checksum for the published application ZIP.

## Major delivered areas

- Secure SSH profiles, host-key trust, reconnect and proxy/bastion routing.
- Remote Explorer and guarded editor workflows.
- Interactive PTY terminal and SSH port forwarding.
- Dashboard, processes, systemd services, storage, network/ports and logs.
- Docker Engine and Docker Compose v2 management with validated raw YAML workflow.
- Git operational helper and scheduled tasks.
- nginx, TLS/Certbot, environment-file and deployment workflows.
- UFW/firewalld, users/groups/authorized keys, APT/DNF and audited administration.
- Backup/restore workflows with capability-specific verification.
- Database runtime/diagnostics/tunneling for PostgreSQL, MySQL, MariaDB, Redis, Microsoft SQL Server and MongoDB; certified backup/restore only where explicitly listed in the support matrix.
- Global dashboard, server comparison and guarded multi-server metadata workflows.
- Optional `serverdesk-agent` backend with loopback-only SSH-tunneled gRPC, realtime metrics/events/logs, signed artifact verification and reviewed lifecycle execution.

## Certified database boundaries in this release

See [`../SUPPORT_MATRIX.md`](../SUPPORT_MATRIX.md) for exact fixture versions and evidence.

Important limitations:

- Redis backup/restore is **Unsupported**.
- MongoDB backup/restore is certified only for the listed **standalone** topology/version.
- Arbitrary SQL execution, Mongo shell execution and a general database query console are outside the certified V1 database scope.

## Optional agent distribution note

The optional agent implementation and lifecycle/security boundary are present in the repository, but this release does **not** publish an unsigned agent binary as an installable lifecycle artifact. ServerDesk's agent install/update flow requires authenticated release metadata and exact artifact verification; the corresponding private signing key is intentionally external to the repository. Agentless SSH operation remains the normal V1 path.

## Platform boundary

- Certified client target: Windows 11 x64.
- Windows 10 x64 remains a compatibility target where the dependency stack supports it.
- Primary certified Linux server targets: Ubuntu 24.04 LTS, Ubuntu 26.04 LTS and Debian 13.

## Explicit V1 non-goals

Kubernetes, Podman management, Linux graphical remote desktop, AWS/Azure/GCP consoles, full database/Git IDE behavior, raw nftables visual editing, destructive disk partition/filesystem management, full SysV-init certification and a public/non-SSH agent management listener are outside this release's certified scope.

## Integrity and safety

The V1 development workflow requires exact-head CI before merge and post-merge CI on the exact merge commit for certified slices. Remote mutations use explicit risk/confirmation/verification semantics, and uncertain completion is not treated as permission for blind destructive retry.
