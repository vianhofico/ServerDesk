# ServerDesk v1.0.4

**English** | [Tiếng Việt](v1.0.4.vi.md)

ServerDesk v1.0.4 focuses on a more consistent Windows operations experience, safer command handling, reproducible frontend builds, and a deterministic Windows shortcut icon.

## Highlights

- Fixes the Windows Desktop and Start Menu shortcut icon by installing the official `serverdesk.ico` branding file alongside the app and referencing that ICO directly from shortcuts.
- Uses the same installed branding ICO for the Windows uninstall display icon while keeping the normalized embedded icon path for the setup executable.
- Strengthens installer smoke coverage so release validation checks the installed branding file and shortcut icon targets.
- Establishes a shared V1 workspace shell, durable UI/UX contracts, reusable operational styles, localized navigation, and persistent server context.
- Redesigns Remote Explorer, Process Manager, Service Manager, Docker Inventory, Scheduled Tasks, and Storage as denser Windows-style operational workspaces with clearer state, filtering, details and command hierarchy.
- Adds English and Vietnamese localization resources across the redesigned workspaces.
- Hardens POSIX SSH command construction by rejecting NUL-bearing executable, argument, environment and working-directory tokens before dispatch.
- Makes TerminalFrontend dependency installation reproducible with a committed npm lockfile and `npm ci`.

## Windows installer

For the normal Windows experience, download and run `ServerDesk-v1.0.4-win-x64-setup.exe`.

The installer creates a Desktop shortcut by default and a Start Menu shortcut. Both now reference the installed official ServerDesk ICO directly, avoiding Windows Shell fallback behavior from executable icon resources.

`ServerDesk-v1.0.4-win-x64.zip` remains available as the portable package.

## Release safety

The release pipeline publishes only the exact Windows release candidate that passes the Release Publish Smoke workflow for the certified `main` commit. The pipeline verifies installer creation, installation, shortcuts, branding icon path, application launch, uninstall behavior, artifact provenance and SHA-256 checksums before publishing.

> Public binaries are currently not Authenticode/code-signed, so Windows SmartScreen may show an unknown-publisher warning.
