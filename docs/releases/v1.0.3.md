# ServerDesk v1.0.3

**English** | [Tiếng Việt](v1.0.3.vi.md)

ServerDesk v1.0.3 adds a normal Windows installation experience while keeping the portable package available.

## Added

- Adds `ServerDesk-v1.0.3-win-x64-setup.exe`, a per-user Windows installer.
- The installer creates a ServerDesk Desktop shortcut by default and a Start Menu shortcut.
- ServerDesk is registered in Windows **Settings → Apps → Installed apps** with an uninstaller.
- The installer, installed app and shortcuts use the existing official `serverdesk.ico` branding already embedded by the WPF application.
- Uses a stable installer application ID so future installer releases can upgrade the same installed application.
- Keeps `ServerDesk-v1.0.3-win-x64.zip` as the portable alternative.

## Release safety

The release smoke now verifies the complete installed-app path before an installer can be published:

1. publish the self-contained Windows x64 app;
2. launch the published GUI and verify a stable visible `ServerDesk` main window;
3. compile the Windows installer;
4. install it silently as the current user;
5. verify the installed EXE, Desktop shortcut, Start Menu shortcut, icon source and Windows uninstall registration;
6. launch the installed application and verify the GUI remains stable;
7. uninstall and verify the executable, shortcuts and uninstall registration are removed;
8. only then package the setup EXE and portable ZIP for release.

`SHA256SUMS.txt` contains checksums for both release artifacts.

## Install

For the normal Windows experience, download and run `ServerDesk-v1.0.3-win-x64-setup.exe`. After installation, open ServerDesk from the Desktop or Start Menu.

See [Windows installation guide](../INSTALL.md).

> Public binaries are currently not Authenticode/code-signed, so Windows SmartScreen may show an unknown-publisher warning.

No certified server/database feature-scope boundaries change in this release.
