# ServerDesk v1.0.1

**English** | [Tiếng Việt](v1.0.1.vi.md)

ServerDesk v1.0.1 is a startup hotfix for the Windows client.

## Fixed

- Fixes an application startup failure introduced in v1.0.0 where Microsoft.Extensions.DependencyInjection could not choose between two public constructors on `SshAgentTunnelSessionFactory`.
- Keeps `IPortForwardSessionFactory` as the single DI composition path for agent SSH tunneling instead of bypassing the registered port-forward factory.
- Adds a regression test that builds the same application service graph with `ValidateOnBuild = true` and `ValidateScopes = true`, matching the startup validation path that exposed the issue.

## Upgrade from v1.0.0

1. Download `ServerDesk-v1.0.1-win-x64.zip` from this release.
2. Extract it to a new folder or replace the previous extracted application files.
3. Run `ServerDesk.App.exe`.

No certified feature scope or database support boundaries change in this hotfix. See [`../CURRENT_SCOPE.md`](../CURRENT_SCOPE.md), [`../USER_GUIDE.md`](../USER_GUIDE.md), and [`../SUPPORT_MATRIX.md`](../SUPPORT_MATRIX.md) for the V1 scope and usage documentation.
