# ServerDesk v1.0.0

[English](v1.0.0.md) | **Tiếng Việt**

ServerDesk v1.0.0 là release V1 tổng hợp đầu tiên sau khi roadmap M0–M8 của repository được hoàn thành.

## Release này là gì

Windows x64 desktop client để quản trị Linux server bằng SSH/SFTP/PTY làm lớp điều khiển bảo mật chính, kèm optional realtime agent infrastructure chạy qua SSH tunnel.

Release workflow publish:

- `ServerDesk-v1.0.0-win-x64.zip` — package Windows x64 self-contained;
- `SHA256SUMS.txt` — SHA-256 checksum của ZIP ứng dụng.

## Các nhóm chức năng chính đã có

- SSH profile an toàn, host-key trust, reconnect và proxy/bastion routing.
- Remote Explorer và guarded editor.
- Interactive PTY terminal và SSH port forwarding.
- Dashboard, processes, systemd services, storage, network/ports và logs.
- Docker Engine và Docker Compose v2 với raw YAML được validate trước apply.
- Git operational helper và scheduled tasks.
- nginx, TLS/Certbot, environment-file và deployment workflow.
- UFW/firewalld, users/groups/authorized keys, APT/DNF và administration có audit.
- Backup/restore với verification theo capability.
- Database runtime/diagnostics/tunneling cho PostgreSQL, MySQL, MariaDB, Redis, Microsoft SQL Server và MongoDB; backup/restore chỉ certify ở capability/version/topology được ghi rõ.
- Global dashboard, server comparison và guarded multi-server metadata workflows.
- Optional `serverdesk-agent` backend: loopback-only gRPC qua SSH tunnel, realtime metrics/events/logs, signed artifact verification và lifecycle executor đã review.

## Boundary database của release

Xem [`../SUPPORT_MATRIX.vi.md`](../SUPPORT_MATRIX.vi.md) để biết exact fixture/version/evidence.

Giới hạn quan trọng:

- Redis backup/restore: **Unsupported**.
- MongoDB backup/restore: chỉ certify cho **standalone topology/version** đã liệt kê.
- Arbitrary SQL execution, Mongo shell execution và general database query console nằm ngoài certified V1 scope.

## Lưu ý về phân phối optional agent

Implementation và lifecycle/security boundary của optional agent đã có trong repository, nhưng release này **không publish một agent binary unsigned rồi coi đó là lifecycle artifact có thể cài**. Luồng install/update của ServerDesk yêu cầu authenticated release metadata và exact artifact verification; private signing key tương ứng cố ý nằm ngoài repository. Agentless SSH vẫn là đường sử dụng thông thường của V1.

## Platform boundary

- Certified client target: Windows 11 x64.
- Windows 10 x64 là compatibility target khi dependency stack còn hỗ trợ.
- Primary certified Linux server targets: Ubuntu 24.04 LTS, Ubuntu 26.04 LTS và Debian 13.

## Những thứ V1 không claim

Kubernetes, Podman management, Linux graphical remote desktop, AWS/Azure/GCP console, full database/Git IDE, raw nftables visual editing, destructive disk partition/filesystem management, full SysV-init certification và public/non-SSH agent management listener nằm ngoài certified scope của release này.

## Integrity và safety

Workflow phát triển V1 yêu cầu exact-head CI trước merge và post-merge CI trên đúng merge commit cho các slice được certify. Remote mutation có risk/confirmation/verification rõ ràng; completion không chắc chắn không được coi là lý do để blind retry destructive operation.
