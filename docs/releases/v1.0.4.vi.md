# ServerDesk v1.0.4

[English](v1.0.4.md) | **Tiếng Việt**

ServerDesk v1.0.4 tập trung vào trải nghiệm vận hành Windows nhất quán hơn, xử lý lệnh an toàn hơn, build frontend có thể tái lập và icon shortcut Windows hiển thị ổn định.

## Điểm nổi bật

- Sửa icon shortcut trên Desktop và Start Menu bằng cách cài file branding chính thức `serverdesk.ico` cùng ứng dụng và cho shortcut tham chiếu trực tiếp tới file ICO này.
- Dùng cùng file ICO đã cài cho icon hiển thị trong mục gỡ cài đặt của Windows, đồng thời vẫn giữ icon đã normalize riêng cho file setup.
- Tăng cường installer smoke test để kiểm tra file branding đã cài và đường dẫn icon của shortcut.
- Thiết lập V1 workspace shell dùng chung, UI/UX contract ổn định, style vận hành tái sử dụng, điều hướng đa ngôn ngữ và server context xuyên suốt.
- Thiết kế lại Remote Explorer, Process Manager, Service Manager, Docker Inventory, Scheduled Tasks và Storage thành các workspace vận hành theo phong cách Windows, dày thông tin hơn và rõ ràng hơn về trạng thái, bộ lọc, chi tiết và thao tác.
- Bổ sung resource tiếng Anh và tiếng Việt cho các workspace đã thiết kế lại.
- Gia cố dựng lệnh POSIX qua SSH bằng cách từ chối token chứa ký tự NUL ở executable, argument, environment và working directory trước khi gửi lệnh.
- Làm cho quá trình cài dependency của TerminalFrontend có thể tái lập bằng npm lockfile và `npm ci`.

## Bộ cài Windows

Để cài đặt theo cách thông thường trên Windows, tải và chạy `ServerDesk-v1.0.4-win-x64-setup.exe`.

Bộ cài tạo shortcut ngoài Desktop theo mặc định và shortcut trong Start Menu. Cả hai giờ tham chiếu trực tiếp tới file ICO chính thức của ServerDesk đã được cài, tránh trường hợp Windows Shell fallback sang icon mặc định từ resource của executable.

`ServerDesk-v1.0.4-win-x64.zip` vẫn được cung cấp dưới dạng portable.

## An toàn phát hành

Pipeline chỉ publish đúng Windows release candidate đã vượt qua Release Publish Smoke cho commit `main` được chứng nhận. Trước khi phát hành, pipeline kiểm tra build installer, quá trình cài đặt, shortcut, đường dẫn branding icon, khởi chạy ứng dụng, uninstall, provenance của artifact và SHA-256 checksum.

> Binary public hiện chưa được ký Authenticode/code-sign nên Windows SmartScreen có thể hiển thị cảnh báo unknown publisher.
