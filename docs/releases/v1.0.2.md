# ServerDesk v1.0.2

**English** | [Tiếng Việt](v1.0.2.vi.md)

ServerDesk v1.0.2 fixes a post-startup WPF crash that could make the main window appear blank briefly and then close on Windows.

## Fixed

- Fixes `CapabilitySummaryControl` loading a `StaticResource` (`SecondaryButton`) before the control is attached to `MainWindow`, which could throw during the WPF `Loaded` phase.
- Uses a deferred dynamic resource lookup for that parent-owned style so the control can be constructed safely before it enters the main window visual/logical tree.
- Adds application-level handling for otherwise-unhandled WPF dispatcher exceptions. ServerDesk now writes a secret-safe diagnostic to `%LOCALAPPDATA%\ServerDesk\Logs\startup-crash.log`, shows the diagnostic path, and shuts down deliberately instead of disappearing silently.
- Diagnostic reports intentionally omit exception messages and `Exception.Data` to avoid persisting user/remote values that could contain secrets.
- The release smoke workflow now launches the actual published `ServerDesk.App.exe`, requires a visible main window, and verifies the process/window remain alive for a bounded stability period before the package may be released.

## Upgrade from v1.0.1

1. Download `ServerDesk-v1.0.2-win-x64.zip` from this release.
2. Extract it to a new folder.
3. Run `ServerDesk.App.exe`.

No certified feature scope or database support boundaries change in this hotfix.
